# 电脑异常显示工具

一个轻量的 Windows 小工具：在**不破坏系统、不损坏任何本地文件**的前提下，让电脑全屏显示仿真「电脑异常」页面（蓝屏 / 违规外联），并支持**定时触发**。

> 仅用于授权环境下的演示、测试或整蛊，**切勿在未告知对方的情况下用于他人电脑**。

---

## 功能特性

- **两种异常页面可选**
  - **蓝屏效果**：仿真 Windows 11 蓝屏，含可扫描二维码（指向 `windows.com/stopcode`）。
  - **违规外联**：仿真「此计算机因违规外联已被阻断」全屏警示页。
- **定时显示**：在控制面板填入 `HH:MM`，到点自动全屏显示；若时间已过则顺延至次日。
- **立即测试**：不填时间，直接预览效果。
- **全屏置顶**：异常页始终覆盖整个屏幕并置顶。
- **键盘锁定**：显示期间禁用几乎所有按键，**仅保留 `Win` 与 `R`**，方便通过运行框输入 `shutdown /s /t 10` 关机恢复。
- **紧急退出**：异常页显示时按 **`F10`** 立即退出。
- **自动静音**：异常页出现时系统静音，按 `F10` 退出后恢复原来的声音状态。
- **最小化到托盘**：定时进行中关闭主窗口不会终止定时，程序会缩到系统托盘继续运行，到点照常弹出。

---

## 使用方法

1. 双击运行仓库中的 `电脑异常显示工具.exe`（单文件，无需安装、无需 Python、无需联网）。
2. 在顶部下拉框选择异常类型：**蓝屏效果** 或 **违规外联**。
3. 选择触发方式：
   - **立即测试**：马上显示效果。
   - **启动定时**：在「触发时间 (HH:MM)」填入时间（如 `14:30`），到点自动显示。
4. 退出异常页面：**按 `F10`**。
5. 恢复系统（若卡住）：`Win + R` → 运行 → 输入 `shutdown /s /t 10`（10 秒后关机）。

### 关于关闭窗口
- 若已设定定时，点击右上角 ✕ 会**最小化到系统托盘**，定时继续运行（不会终止）。
- 托盘图标：左键双击恢复窗口；右键菜单可「显示窗口 / 退出」。
- 未设定定时时，点 ✕ 即正常退出。

## 注意事项

- **杀毒软件误报**：PyInstaller 打包的单文件 exe 常被 Windows Defender 等误判为病毒。若无法运行或被删除，请将本文件加入白名单 / 允许运行（这是打包特征，并非真实病毒）。
- **系统要求**：仅支持 **Windows（64 位）**，Win7 / Win10 / Win11 均可。macOS、Linux 无法运行。
- **高分屏**：已在代码层面处理 DPI 缩放，标题与正文不会被裁切。
- **仅显示，不破坏**：工具只绘制全屏画面并锁定键盘，不修改、不删除任何系统文件或数据。
